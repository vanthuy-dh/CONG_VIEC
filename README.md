# CONG_VIEC – Kho làm việc của Phòng KCM với Claude Code

## Cách sử dụng hằng ngày

1. **Đưa số liệu vào đúng thư mục** (trên GitHub: mở thư mục → `Add file` → `Upload files` → kéo thả file → bấm `Commit changes`):
   - Số liệu thực hiện → `01_KHOI_LUONG_MO/`
   - Số liệu kế hoạch → `02_KE_HOACH/`
   - Báo cáo mẫu đã gửi → `03_BAO_CAO/`
2. **Mở Claude Code** tại claude.ai/code, chọn kho `CONG_VIEC`.
3. **Giao việc**, ví dụ:
   - "Lập báo cáo tháng 10/2026 từ file khối lượng mỏ, so sánh với kế hoạch."
   - "Làm bộ PowerPoint 10 trang đánh giá 9 tháng năm 2026."
4. **Nhận kết quả** trong thư mục `99_KET_QUA/`, tải về kiểm tra.

## Quy tắc chung

Quy tắc Claude phải tuân theo nằm trong file `CLAUDE.md`. Muốn thay đổi cách Claude làm việc, chỉ cần sửa file này.

## Lưu ý bảo mật

Kho nên để chế độ **Private**. Không đưa tài liệu mật, thông tin cá nhân nhạy cảm lên kho.
